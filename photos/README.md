# Put her photos here

Drop JPG, PNG or WebP photos in this folder, then run `npm run dev` or `npm run build`.

- They fill the 80 photo spots in file-name order (`01.jpg`, `02.jpg` …) and repeat if there are fewer. 30 or more look best.
- The first becomes the cover, and the second the big photo on the last page.
- To put a photo in one exact spot, name it after the spot: `cover.jpg`, `finale.jpg`, `camera-03.jpg`. Every placeholder shows its spot's name.
- iPhone HEIC photos need saving as JPG first.

This folder is ignored by git, so the photos stay on your computer.
